# Ricardo AI 工具（GPT AT Refresh 精简版）

主要用于把现成的 ChatGPT 账号（邮箱----密码----2FA）导进来，配好代理，一键刷新 access_token，并提供独立的安全工具入口。

由完整版裁剪而来，包含 **导入账号**、**代理池**、**运行记录**，以及独立的 **密码 / 2FA**、**2FA 验证码** 和 **GPT 注册机** 入口。密码 / 2FA 与注册机仍依赖各自的本地服务；2FA 验证码页面无需额外服务。

---

## 一、启动

1. 双击 `start_webui.py`（需已安装 Python 3.10+；首次运行会按 `requirements.txt` 自动安装依赖）。
2. 浏览器自动打开 `http://127.0.0.1:8768/`。
3. 换端口：`python start_webui.py --port 9000`
4. 缺依赖可手动安装：`pip install -r requirements.txt`

## 二、导入账号

点页面右上角 **「＋ 添加账号」**，每行一条粘贴：

```
邮箱----密码----2FA密钥
```

- 分隔符是 **四个减号 `----`**。
- 行尾多出的字段（如旧的 access_token）会被忽略，不影响导入。
- 重复邮箱只更新密码/2FA，已刷新出的 token 与原导入时间保留。
- 有一行格式不对，只跳过那一行并在结果里提示，不影响其余行。

## 三、刷新AT

1. 勾选要刷新的账号（支持全选当前页）。
2. 点 **「刷新AT (N)」** → 确认。
3. 程序按三路径级联自动刷新，轮换出的新 RT / session_token 会自动写回：
   - 有 refresh_token → OAuth 直换（秒级）
   - 无 RT / RT 失效 → session_token 会话直提（秒级）
   - 两者都无（新导入的号）→ 用 密码+2FA 直接登录拿会话（单个约几十秒）

刷新完成后，`access` / `session` / `refresh` 列的数字就是各凭证长度，点数字即可复制对应 token。

## 四、代理池

1. 到「代理池」页粘贴代理，每行一个：`[协议://][user:pass@]host:port`，不写协议默认 HTTP，SOCKS5 必须写 `socks5://`。
2. 点「覆盖保存」→ 可用「测试全部」验证连通性。
3. 回到「导入账号」页，在代理下拉框中选择要用的代理（留空 = 直连）。
4. 勾选 **不超过 2 个**账号时一律串行。勾选 **>2 个**时按所选并发一起跑：代理下拉留空 = 本机 IP 直连，不轮询代理池；下拉选中 1 个代理且代理池 **≥2 个**时按整池轮询；代理池只有 1 个时自动降为串行（防同 IP 风控关联）。

> 建议：批量刷新前先在代理池测试好代理；账号被封与刷新失败多与代理质量相关。

## 五、导出 / 删除

- **导出选中 / 导出全部**：多种格式（凭证 TXT、CPA JSON ZIP 等），可先下载保留，也可「下载并删除」一键清理。
- **删除选中 / 清空全部**：只删本地记录，不会动 OpenAI 侧账号。

## 六、动态流量（重要，务必阅读）

本工具批量登录/刷新时需要 **动态流量（动态 IP 代理）**，例如 1024、711 等动态流量套餐。
有需要的可以上 **咸鱼** 搜索购买。

> ⚠️ **特别强调：本地电脑使用动态流量，必须开启代理软件的 虚拟网卡 TUN 模式！**
> 不开 TUN 模式时，流量不走虚拟网卡，工具的请求仍从本机真实 IP 直连发出，
> 批量登录极易触发 OpenAI 风控导致封号，动态流量等于白买。
> 常见代理软件（Clash / sing-box / v2rayN 等）均在设置里有 TUN / 虚拟网卡 开关，开启即可。

## 七、其他功能
- **刷新refresh（补 RT）**：对缺 refresh_token 的号重新登录授权拿新 RT。⚠️ 已接码的账号才能刷新 RT，不然会报错。任务在后台执行，进度见「运行记录」页。
- **检测选中 / 检查未检测**：检测账号是 Free / 可领Plus / 已封号 / 凭证失效，结论显示在表格「Plus / 时间」列。
- **运行记录**：左侧菜单「运行记录」页可查看每次后台任务的运行过程与结果（run_id、邮箱、状态、错误信息）。
- **筛选**：「全部」下拉框支持 有RT / 无RT / 缺AT / 未检测 / Free / 可领Plus / 已封号 / 凭证失效 等筛选。

## 八、常见问题

| 现象 | 处理 |
| --- | --- |
| 刷新报「需要邮箱验证码」 | 该号登录时被 OpenAI 要求邮箱 OTP，本工具不带邮箱取件，无法处理此类号 |
| 一直超时 / 连接失败 | 代理不可用或被 OpenAI 风控，换代理再试 |
| 刷新失败会怎样 | 失败号不落库，原凭证原样保留，可重试 |
| 数据存在哪 | 本目录 `webui/webui.db`（SQLite），整个文件夹拷走即备份 |

## 九、本地 2FA 验证码

打开左侧「安全工具 → 2FA 验证码」，或访问 `http://127.0.0.1:8768/#/2fa-code`。

1. 粘贴已有的 Base32 2FA 密钥或 `otpauth://totp/` 链接，点击「生成验证码」。
2. 普通密钥默认生成 SHA-1 / 6 位 / 30 秒 TOTP；链接中的算法、位数与周期会自动读取。
3. 验证码按周期自动更新，点击「复制验证码」仅复制数字。
4. 「清空」、刷新页面或切换到其他功能时，会清除本页输入与结果。

全部运算使用浏览器 Web Crypto，不调用 2fa.run 或任何验证码 API，不读取账号库，不将密钥写入 localStorage、sessionStorage、Cookie 或数据库。此页面不提供短信/邮箱接码，也不能恢复遗失的 2FA 密钥。系统剪贴板由用户主动复制时写入验证码，请勿在共享设备上保留敏感内容。

需要支持 Web Crypto 的现代浏览器，以及 HTTPS 或 `localhost` / `127.0.0.1` 地址。验证码无效时，请检查密钥并开启电脑时间自动同步。

前端验证（Node.js 20+）：在 `webui/frontend` 运行 `npm test`；构建运行 `npm run build`，产物写入 `webui/static`，由当前本地服务提供。

## 十、密码 / 2FA 模块的界面集成

「密码 / 2FA」页面仍由独立的 `Change-2fa-Password-GPT-Auto` 服务（默认 `127.0.0.1:5033`）提供，不合并账号数据、任务队列或业务 API。嵌入模式统一使用 Ricardo AI 的暖白 / 陶土橙主题，并跟随主站切换深色模式；主题切换不会重载业务页面。

独立服务的 `static/embedded.js` 仅交换主题和布局高度，校验消息来源及目标；`static/ricardo-embedded.css` 仅在 `embedded=1` 时生效。直接打开独立服务时保留其原有界面。部署或分享整套工具时，需要同时携带独立服务更新后的静态文件，不能只复制本项目的 `webui/static`。

## 十一、GPT 注册机的界面集成

「GPT 注册机」采用同样的嵌入主题及自动测高方式，保留独立服务 `http://localhost:5050`、原有 iframe sandbox 和授权逻辑，不共享主面板的账号库或任务队列。主题切换仅发送展示消息，不重载注册页面。

配套文件位于注册机仓库的 `webui/static/embedded.js`、`webui/static/ricardo-embedded.css` 以及 `webui/templates/index.html`、`login.html`。嵌入时内存状态卡放到页面底部，不覆盖独立站的拖拽偏好；直接打开独立站仍保留原界面。登录重定向后也能恢复嵌入主题，授权规则未改变。

Flask 默认会缓存模板，更新模板后应先确认无运行中任务再重启注册机服务。展示桥接测试可在该服务仓库运行 `node --test tests/embedded-ui.test.mjs`。

## 十二、Muse 注册机（可选独立服务）

主面板已提供「Muse 注册机」入口，但不会内置或合并第三方 Muse 注册机源码。使用时请单独审计并运行 [ludwigxs/muse-register](https://github.com/ludwigxs/muse-register)。如果 `muse-register` 放在工具包根目录，根目录的 `start_all.py` 会自动启动它；也可以手动运行：

```bash
git clone https://github.com/ludwigxs/muse-register.git
cd muse-register
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python web.py --host 127.0.0.1 --port 8801
```

然后打开 RicardoAI 的「Muse 注册机」菜单。Muse 使用独立的 `muse.sqlite3`、邮箱池、卡池、代理池和任务队列，不与本工具的 `webui/webui.db` 共享。不要把真实银行卡、邮箱密码、代理密码或 Token 提交到未审计的服务中。
